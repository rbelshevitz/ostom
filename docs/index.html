Outlook PST/OST recovery

Recover readable mail from a damaged Outlook file.

OSTOM carefully extracts messages and attachments from PST/OST files, exports them to open formats, and leaves the source file untouched.

Read-only · local processing · mbox and EML · honest reporting

What OSTOM does

It does not rewrite the file — it saves what can still be read.

When Outlook can only partly read a PST or OST, OSTOM exports the available messages and attachments to a Thunderbird-compatible format and reports damaged areas separately.

01

The source stays untouched

The utility is read-only and never overwrites the PST/OST.

02

Open export formats

Open the result in Thunderbird or save messages as mbox and individual EML files.

03

Honest reporting

Exported, partial, failed, and duplicate results are clearly distinguished.

Quick start

Work from a copy of the source file.

Write the result to a separate folder and check it in Thunderbird before deleting the original or its backup.

Inspect the structure and save a report
.\ostom.exe -json -output-dir E:\recovered source-copy.ost
Export readable mail
.\ostom.exe -export-dir E:\recovered source-copy.ost
Run the additional recovery pass
.\ostom.exe -recovery-scan -export-dir E:\recovered source-copy.ost
