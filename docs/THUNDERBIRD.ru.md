# Загрузка результата OSTOM в Thunderbird

OSTOM должен экспортировать Local Folders Thunderbird в стандартной структуре mbox:

```text
output/
├── Local Folders/
│   ├── Local Sent
│   ├── Local Sent.sbd/
│   │   ├── 2022
│   │   └── 2023
│   └── Archive
└── report.json
```

Каждая почтовая папка — это файл без расширения. Если у папки есть подпапки, должны существовать оба объекта:

```text
FolderName       # mbox с письмами
FolderName.sbd/  # подпапки
```

Файлы индексов `.msf` создаёт сам Thunderbird. OSTOM не должен их создавать: старые индексы могут скрывать письма или показывать неправильное количество.

## Рекомендуемый импорт

1. Создать или открыть профиль Thunderbird.
2. Один раз запустить Thunderbird, чтобы появилась папка `Local Folders`.
3. Полностью закрыть Thunderbird.
4. Сделать резервную копию профиля Thunderbird.
5. Скопировать содержимое `Local Folders` из результата OSTOM в каталог профиля `Mail/Local Folders/`.
6. Запустить Thunderbird.
7. Дождаться перестроения индексов папок.

Обычно профиль находится здесь:

```text
%APPDATA%\Thunderbird\Profiles\<profile>\
```

Для больших или сомнительных импортов лучше использовать новый профиль Thunderbird или расширение ImportExportTools NG. Импортировать нужно в `Local Folders`, а не сразу в рабочую IMAP-папку. Это не позволит случайно загрузить локальные восстановленные письма на сервер.

## Правила безопасности

- Копировать результат, а не перемещать единственную копию.
- Хранить `report.json` рядом с экспортом.
- Не копировать старые `.msf` из прежнего профиля.
- Не импортировать в IMAP, пока локальный результат не проверен.
- Сохранять исходный OST и отчёт OSTOM.

Локальное хранилище Thunderbird использует исходные сообщения RFC 5322 в mbox-файлах и отдельную базу `.msf` для каждой папки. Данные — это mbox; `.msf` — перестраиваемый индекс.
